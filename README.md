# Tobenna Nwafor

BSc Computer Science (**Games Technology**) — Nottingham Trent University.

I build **interactive systems**: Unreal Engine VR, Android, and real-time 3D. Final-year project used **Unreal Engine + OpenXR** (Meta Quest 2) to test biophilic VR scenes for stress and mood. Other work includes a campus GPS treasure-hunt app, custom 3D physics in Processing, and a second Unreal VR prototype (Corsi block-tapping).

**GitHub:** [NWAFORTY](https://github.com/NWAFORTY)

## Unreal Engine / VR

Both the **FYP** and **CorsiVR** are Unreal Engine OpenXR projects (headset-first, Quest 2 / PCVR). The FYP adds a wellbeing evaluation protocol; CorsiVR is a complete in-headset memory game (sequences, pressure plates, menus, scoring).
